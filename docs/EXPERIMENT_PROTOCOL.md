# 实验协议（开始 GPU 实验前冻结）

## 研究问题

在相同教师、相同未标注视频集合、相同人工审计预算下：

1. 时序一致性筛选是否改善伪标签 precision 而不损害 pedestrian/rider recall？
2. 有效伪标签是否给学生训练带来样本外 COCO mAP 增益？
3. 面对夜间、雨天、遮挡、短时目标，是否会出现系统性回退？

## 阶段 / 对照

- B0：人工标注监督训练（已实现训练接口，待跑）。
- B1：固定置信度筛选 + 离线自训练（代码已实现，待跑）。
- B2：论文 Soft Teacher 在线 EMA 教师-学生复现（待实现；不能用离线重训冒充）。
- B3：B1 + 时序筛选（代码已实现，待跑）。
- B4：B3 + track confidence 方差惩罚（代码已实现，待跑）。
- B5：B4 + 人工标注预算限制下的复核闭环（人工回填接口/成本统计待实现）。

重要：由于 B3/B4 的输入是基于 ByteTrack 的视频轨迹，而 B1 也应采用同一 track-video 输出，仅替换筛选方法，以避免推理差异造成虚假收益。

## 数据分区

- 官方 BDD detection train：监督数据和训练内未标注/模拟未标注视频；必须按视频组切分。
- 内部审计 train 分区：用于研究策略诊断与抽样 GT 审计；调参集与最终冻结审计集应再次分开。
- 官方 BDD val：所有模型最终对比；固定划分，无训练使用。
- 不得为了好看重复挑选测试集或偷偷跳过困难样本。
